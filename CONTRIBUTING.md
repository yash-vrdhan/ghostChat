# Contributing

## Setup
1. Create a virtual environment
2. Install deps with `pip install -e .[dev]` (or `poetry install`)
3. Run tests with `pytest`

## Ground Rules
- Keep changes small and focused
- Preserve learning clarity in code/comments
- Prefer explicit protocol changes over implicit behavior

## Pull Requests
- Include a short summary
- Include manual test steps
- Ensure tests pass in CI
